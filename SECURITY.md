# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne pas publier une vulnérabilité de sécurité dans une issue publique.

Pour un signalement confidentiel, contactez directement le propriétaire du dépôt via son profil GitHub :

- Profil : https://github.com/migueldevstack-maker
- Dépôt : https://github.com/migueldevstack-maker/djassa-proo

Incluez si possible :

- une description claire du problème ;
- les étapes pour le reproduire ;
- l'impact potentiel ;
- une proposition de correction, si vous en avez une.

## Secrets et données personnelles

Ne committez jamais de secrets, mots de passe, clés API, pièces d'identité, numéros de téléphone réels ou données utilisateurs. Si un secret est publié par erreur, révoquez-le immédiatement et remplacez-le ; supprimer le fichier ne suffit pas, car il peut rester dans l'historique Git.
